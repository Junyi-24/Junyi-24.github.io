# Junyi Li

Personal academic homepage of **Junyi Li** (李俊懿).

🔗 https://junyi-24.github.io/

## Structure

- `index.html` — page skeleton
- `sections/` — one file per page section
- `css/style.css` — styles (light/dark themes, responsive)
- `js/main.js` — section loader and theme toggle
- `assets/` — images and downloadable files

## Local Preview

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```
